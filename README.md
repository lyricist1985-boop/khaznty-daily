# خزنتي ديلي - Khaznty Daily - مشروع Flutter جاهز

## ازاي تطلع ملف AAB من غير ما تنزل Android Studio

### الطريقة الأسهل - GitHub Actions (مجاني - 5 دقايق)
1. اعمل حساب مجاني على github.com
2. اعمل New Repository باسم khaznty-daily - اختار Public
3. ارفع كل الملفات اللي في الفولدر ده (Upload files) أو اسحبهم
4. روح على تاب Actions فوق
5. هتلاقي Build AAB - دوس Run workflow
6. استنى 4-5 دقايق لحد ما يخلص - هتلاقي علامة صح خضرا
7. انزل تحت في نفس الصفحة - هتلاقي Artifacts - khaznty-aab - دوس عليها وحملها
8. هينزل ملف zip جواه app-release.aab - هو ده اللي هترفعه في Google Play Console > الاختبار الداخلي > انشاء اصدار جديد

### لو عندك Android Studio
1. افتح المشروع
2. Build > Generate Signed App Bundle > Android App Bundle
3. اعمل Key جديد واحفظ الباسورد
4. اختار release > Create
5. الملف هيكون في build/app/outputs/bundle/release/app-release.aab

## اللي جوه التطبيق - النسخة 1.0.0
- الرئيسية: ملخص المصاريف والأدوية والطوارئ
- المصاريف: اضافة مصروف - فواتير - اقساط - فلترة - اجمالي الشهر
- الأدوية: اضافة دواء - الجرعة - المواعيد - تذكير
- العيلة والطوارئ: اسم - صلة القرابة - فصيلة الدم - حساسية - رقم طوارئ - اتصال سريع
- الجمعية: اسم الجمعية - المبلغ - الدور - الأعضاء
- الملفات: تسجيل ملفات مهمة - بطاقة - روشتة - عقد
- الإعدادات: حذف كل البيانات - سياسة الخصوصية - عن التطبيق

## ملاحظة مهمة
البيانات بتتحفظ على جهاز المستخدم فقط (SharedPreferences) - مفيش سيرفر - مفيش تتبع - مفيش اعلانات.
